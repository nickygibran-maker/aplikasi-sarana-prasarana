PROJECT PENGADUAN SARPRAS

1. Import database sarpras dari file SQL yang diberikan.
2. Ekstrak folder project ke C:\xampp\htdocs\pengaduan_sarpras
3. Aktifkan Apache dan MySQL.
4. Buka http://localhost/pengaduan_sarpras/

ADMIN: admin01 / admin123
SISWA: login menggunakan NIS, contoh 1000000001

Fitur hasil yang diharapkan:
ADMIN: list aspirasi keseluruhan, filter tanggal/bulan/siswa/kategori, status penyelesaian, feedback, histori.
SISWA: status penyelesaian, histori aspirasi, feedback, progres perbaikan.

Catatan: database yang diberikan tidak memiliki kolom isi/judul aspirasi dan tanggal langsung pada tabel aspirasi. Tanggal ditampilkan dari tabel histori.
